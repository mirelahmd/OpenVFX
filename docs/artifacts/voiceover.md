# Artifact: voiceover_text.json

Generated by `byom-video creative-voiceover-text`.

Schema version: `voiceover_text.v1`

---

## Location

```
.byom-video/creative_plans/<plan_id>/outputs/voiceover_text.json
.byom-video/creative_plans/<plan_id>/outputs/voiceover_text.txt
```

Both files are written together. The `.txt` file contains the plain `text` field for easy copy-paste into a recording tool or TTS service.

---

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `schema_version` | string | Always `voiceover_text.v1` |
| `created_at` | ISO 8601 | When the artifact was generated |
| `creative_plan_id` | string | Parent plan ID |
| `mode` | string | Always `local_text_extract` (no provider call) |
| `source.source_type` | string | `script_draft`, `script_text`, or `goal` |
| `source.source_artifact` | string | Relative path to source file, or `""` for goal |
| `text` | string | The resolved voiceover text |
| `word_count` | int | Number of words in `text` |
| `request.max_words` | int | Word limit applied (default 120) |
| `request.tone` | string | Tone hint (if provided via `--tone`) |
| `request.source` | string | Source mode requested: `auto`, `script`, or `goal` |
| `warnings` | array | Non-fatal warnings (goal fallback, truncation) |

---

## Source Priority

The command picks the richest available text source:

1. `outputs/script_draft.json` — uses the `text` field from the script draft
2. `outputs/script_draft.txt` — plain text fallback
3. Goal string — wrapped as `"Voiceover for: <goal>"` when no script exists

Run `creative-generate-script` before `creative-voiceover-text` to get voiceover text grounded in the actual script draft.

Override the automatic selection with `--source goal` or `--source script`.

---

## Audio Discovery

`voiceover-status` and `creative-assemble --mix-voiceover` discover audio by checking these filenames in order:

1. `outputs/voiceover.wav`
2. `outputs/voiceover.mp3`
3. `outputs/voiceover.m4a`
4. `outputs/voiceover.aac`

Place your recorded or TTS-generated audio at one of these paths to complete the voiceover workflow.

---

## Readiness States

| State | Meaning |
|-------|---------|
| `ready` | Text and audio both found |
| `missing_audio` | Text present; audio not yet placed |
| `missing_text` | Audio present; `voiceover_text.json` not generated |
| `missing_text_and_audio` | Neither artifact exists |

Check current state with `byom-video voiceover-status <plan_id>`.

---

## Workflow

```
# 1. Generate voiceover text from the script (or goal)
byom-video creative-voiceover-text <plan_id>

# 2. Review the extracted text
byom-video review-voiceover <plan_id>

# 3. Record audio or use a TTS service
#    Save the result as:
#    .byom-video/creative_plans/<plan_id>/outputs/voiceover.wav

# 4. Check readiness
byom-video voiceover-status <plan_id>

# 5. Assemble with voiceover mixed in
byom-video creative-assemble <plan_id> --mix-voiceover

# Or run everything in one make command:
byom-video make <input> --goal "..." --yes --prepare-voiceover --mix-voiceover
```

## Related Commands

| Command | Purpose |
|---------|---------|
| `creative-voiceover-text <plan_id>` | Generate `voiceover_text.json` from script or goal |
| `voiceover-status <plan_id>` | Check text + audio readiness |
| `review-voiceover <plan_id>` | Display text preview and next steps |
| `validate-voiceover <plan_id>` | Validate JSON schema; `--require-audio` checks for audio |
| `validate-creative-plan <plan_id>` | Includes voiceover_text.json in plan-wide validation |
| `creative-assemble <plan_id> --mix-voiceover` | Mix audio into the assembled draft |
| `make ... --prepare-voiceover` | Run voiceover text extraction as step 4d of `make` |
| `make ... --require-voiceover` | Fail if no voiceover audio when `--mix-voiceover` is set |

## Flags

### `creative-voiceover-text`

| Flag | Default | Description |
|------|---------|-------------|
| `--overwrite` | false | Replace existing `voiceover_text.json` |
| `--max-words N` | 120 | Truncate text to N words |
| `--tone <hint>` | — | Tone hint recorded in `request.tone` |
| `--source auto\|script\|goal` | auto | Force a specific text source |
| `--json` | false | Also emit full JSON to stdout |

### `voiceover-status`

| Flag | Default | Description |
|------|---------|-------------|
| `--json` | false | Emit readiness result as JSON |

### `review-voiceover`

| Flag | Default | Description |
|------|---------|-------------|
| `--json` | false | Emit review as JSON |
| `--write-artifact` | false | Write `outputs/voiceover_review.md` |

### `validate-voiceover`

| Flag | Default | Description |
|------|---------|-------------|
| `--require-audio` | false | Fail if no audio file is found |
| `--json` | false | Emit validation result as JSON |

### `make` voiceover flags

| Flag | Default | Description |
|------|---------|-------------|
| `--prepare-voiceover` | false | Run `creative-voiceover-text` as step 4d |
| `--require-voiceover` | false | Fail make if no audio when `--mix-voiceover` is set |
| `--voiceover-max-words N` | 120 | Word limit for step 4d |
| `--voiceover-tone <hint>` | — | Tone hint for step 4d |
