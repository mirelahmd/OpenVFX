# Artifact: job.json

Generated by `byom-video job-create`.

Schema version: `openvfx_job.v1`

---

## Location

```
.byom-video/jobs/<job_id>/job.json        # job artifact
.byom-video/jobs/<job_id>/events.jsonl    # lifecycle event log
```

Job IDs are timestamp-prefixed: `20260509T140000Z-make`, etc.

---

## Fields

| Field | Type | Description |
|---|---|---|
| `schema_version` | string | Always `openvfx_job.v1` |
| `job_id` | string | Unique job identifier (timestamp + action type slug) |
| `created_at` | ISO 8601 | When the job was created |
| `updated_at` | ISO 8601 | When the job was last written |
| `action_type` | string | `make`, `revise_make`, or `validate_creative_assemble` |
| `status` | string | `pending`, `running`, `completed`, `failed`, or `cancelled` |
| `approval_status` | string | `pending`, `approved`, `rejected`, or `not_required` |
| `policy` | object | Execution policy flags |
| `input` | object | Action-specific input parameters |
| `output` | object | Action-specific output (populated after run) |
| `warnings` | array | Non-fatal warnings |
| `errors` | array | Error messages (one per failed run) |
| `next_commands` | array | Suggested follow-up commands |

---

## Status Values

| Status | Meaning |
|---|---|
| `pending` | Job created, not yet run |
| `running` | Execution in progress |
| `completed` | Execution succeeded |
| `failed` | Execution failed |
| `cancelled` | Job was cancelled before or during run |

---

## Approval Status Values

| Approval Status | Meaning |
|---|---|
| `pending` | Waiting for explicit approval |
| `approved` | Approved; ready to run |
| `rejected` | Rejected; cannot be run |
| `not_required` | No approval needed (e.g. validate_creative_assemble) |

---

## Policy Fields

| Field | Default | Description |
|---|---|---|
| `allow_overwrite` | false | Overwrite existing artifacts |
| `allow_provider_calls` | false | Call LLM/TTS providers |
| `allow_external_network` | false | Allow external network access |
| `allow_media_writes` | true | Write media files |

## Input Fields by Action Type

### make

|---|---|---|

|---|---|---|

| Field | Required | Description |
|---|---|---|
| `plan_id` | Yes | ID of the creative plan to validate |

## Event Log Schema (events.jsonl)

Each line is a JSON object:

```json
{"time": "2026-05-09T14:00:00Z", "type": "JOB_CREATED", "details": {"job_id": "...", "action_type": "make", "approval_status": "pending"}}
```

### Event Types

| Event | Description |
|---|---|
| `JOB_CREATED` | Job artifact written |
| `JOB_APPROVED` | Approval granted |
| `JOB_REJECTED` | Approval rejected |
| `JOB_CANCELLED` | Job cancelled |
| `JOB_RUN_STARTED` | Execution started |
| `JOB_ACTION_STARTED` | Action handler invoked |
| `JOB_ACTION_COMPLETED` | Action handler succeeded |
| `JOB_ACTION_FAILED` | Action handler failed |
| `JOB_RUN_COMPLETED` | Execution completed successfully |
| `JOB_RUN_FAILED` | Execution completed with failure |
| `JOB_POLICY_BLOCKED` | Execution blocked by approval gate |

## Agent-Plan Origin

Jobs created by `agent-plan-to-job` include these input fields:

- `agent_plan_id`
- `agent_action_id`

The agent plan records the reverse link in `linked_jobs.json`.
