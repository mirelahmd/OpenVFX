# Artifact: caption_variants.json

Generated by `byom-video creative-caption-variants`.

Schema version: `caption_variants.v1`

---

## Location

```
.byom-video/creative_plans/<plan_id>/outputs/caption_variants.json
```

---

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `schema_version` | string | Always `caption_variants.v1` |
| `created_at` | ISO 8601 | When the artifact was generated |
| `creative_plan_id` | string | Parent plan ID |
| `mode` | string | `ollama` or `stub` |
| `provider` | string | Backend provider (e.g. `ollama`) |
| `model` | string | Model used (e.g. `qwen2.5:7b`) |
| `route` | string | Route key resolved (e.g. `creative.captions`) |
| `backend` | string | Backend name from config |
| `source.source_type` | string | `script_draft`, `script_text`, or `goal` |
| `source.source_artifact` | string | Relative path to source file, if any |
| `style_context` | object | Style pack metadata (null if `--no-style`) |
| `request.count` | int | Requested number of variants |
| `request.max_words` | int | Word limit per caption |
| `request.tone` | string | Tone hint (if provided) |
| `variants` | array | Generated caption variants |
| `warnings` | array | Non-fatal warnings |

### Variant object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Stable variant ID (e.g. `v_001`) |
| `text` | string | Caption text |
| `style` | string | Variant style: `hook`, `caption`, `cta`, `short` |
| `reason` | string | Why this variant was written (from model) |

---

## Source Priority

The command picks the richest available source for caption context:

1. `outputs/script_draft.json` — uses the full script text
2. `outputs/script_draft.txt` — plain text fallback
3. Goal string — used when no script is available

Run `creative-generate-script` before `creative-caption-variants` to get captions grounded in the actual script.
