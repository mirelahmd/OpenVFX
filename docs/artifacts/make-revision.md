## Fields

| Field | Type | Description |
|---|---|---|
| `schema_version` | string | Always `make_revision.v1` |
| `revision_id` | string | `revision_NNNN` (sequential per make) |
| `created_at` | ISO 8601 | When the revision was created |
| `make_id` | string | Parent make ID |
| `request` | string | Original natural-language request |
| `status` | string | `planned`, `completed`, or `failed` |
| `run_id` | string | Run ID from parent make |
| `creative_plan_id` | string | Creative plan ID from parent make |
| `planned_actions` | array | List of planned/executed actions |
| `outputs` | object | Paths to key output artifacts after execution |
| `warnings` | array | Non-fatal warnings |
| `errors` | array | Error messages (one per failed action) |
| `next_commands` | array | Suggested follow-up commands |

---

## Status Values

| Status | Meaning |
|---|---|
| `planned` | Actions planned but not executed (no `--yes`) |
| `completed` | All actions completed (some may have warnings) |
| `failed` | All actions failed |

---

## Action Types

| Type | Requires Provider | Description |
|---|---|---|
| `set_platform` | No | Updates platform preset for next reassemble |
| `set_caption_position` | No | Updates caption position for next reassemble |
| `set_caption_style` | No | Updates caption style for next reassemble |
| `generate_script` | Yes | Runs `creative-generate-script` |
| `generate_captions` | Yes | Runs `creative-caption-variants` |
| `prepare_voiceover` | No | Runs `creative-voiceover-text` |
| `generate_voiceover` | Yes | Runs `creative-generate-voiceover` |
| `mix_voiceover` | No | Reassembles with `--mix-voiceover` |
| `reassemble` | No | Runs `creative-assemble` with current settings |
| `validate` | No | Runs `validate-creative-assemble` |

---

## Action Status Values

| Status | Meaning |
|---|---|
| `planned` | Not yet executed |
| `completed` | Executed successfully |
| `failed` | Execution failed; see `error` field |
| `skipped` | Skipped (e.g. prerequisite failed) |

## Snapshot Files

Before any mutation, the following files are copied into the revision directory (if they exist):

| File | Source |
|---|---|
| `before_make_summary.json` | `.byom-video/makes/<make_id>/make_summary.json` |
| `before_creative_plan.json` | `creative_plans/<plan_id>/creative_plan.json` |
| `before_script_draft.json` | `creative_plans/<plan_id>/outputs/script_draft.json` |
| `before_script_draft.txt` | `creative_plans/<plan_id>/outputs/script_draft.txt` |
| `before_caption_variants.json` | `creative_plans/<plan_id>/outputs/caption_variants.json` |
| `before_voiceover_text.json` | `creative_plans/<plan_id>/outputs/voiceover_text.json` |
| `before_creative_timeline.json` | `creative_plans/<plan_id>/outputs/creative_timeline.json` |
| `before_creative_render_plan.json` | `creative_plans/<plan_id>/outputs/creative_render_plan.json` |
| `before_creative_assemble_result.json` | `creative_plans/<plan_id>/outputs/creative_assemble_result.json` |

MP4, audio, and other binary media files are never copied into the snapshot.

## Make Summary Integration

After a completed revision, `make_summary.json` gains three new fields:

| Field | Type | Description |
|---|---|---|
| `latest_revision_id` | string | Most recent revision ID |
| `revision_count` | int | Number of revisions performed |
| `revision_status` | string | Status of the latest revision |

These fields are omitted when no revisions have been run.
