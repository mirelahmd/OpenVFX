# Create Session Artifact

`create_session.json` records a single scoped create session.

Path:

```text
.byom-video/create_sessions/<create_session_id>/create_session.json
```

Schema version:

- `openvfx_create_session.v1`

It records:

- session id
- input path and goal
- session status
- scoped approval settings
- linked agent plan and graph decision paths
- linked jobs path
- deliverable paths
- capability gaps
- warnings/errors
- next commands

Related files:

```text
.byom-video/create_sessions/<create_session_id>/create_review.md
.byom-video/create_sessions/<create_session_id>/linked_agent_plan.json
.byom-video/create_sessions/<create_session_id>/linked_jobs.json
.byom-video/create_sessions/<create_session_id>/events.jsonl
```

The scope is not global configuration. It applies only to this create session and its linked plan/jobs.

`create_review.md` is the human-facing review page. It is regenerated by:

```sh
./byom-video create-result <create_session_id> --write-artifact
```

It includes creative brief, deliverables, asset requirements, visual generation dry-run requests, capability gaps, agent plan details, linked jobs, outputs, and next commands.
